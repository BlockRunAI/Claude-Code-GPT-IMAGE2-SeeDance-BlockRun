# Contributing

Thanks for helping grow the BlockRun art bundle. Two kinds of contributions are
especially welcome: **new slash commands** and **new prompt cases**.

## Before you open a PR

Run the same checks CI runs:

```bash
bash -n install.sh uninstall.sh skills/launch-film/finish.sh skills/launch-film/sound-design.sh
python3 -m py_compile scripts/*.py
python3 -c "import json; json.load(open('plugin.json')); json.load(open('.mcp.json'))"
grep -rniE "your majesty|陛下" . --include='*.md' --include='*.json' --include='*.py' | grep -v case-library/ && echo "LEAK" || echo "clean"
```

If you touched a `skills/launch-film/starter*/` composition, also run
`npm run check` inside a copy of that starter (lint + validate + inspect must be clean).

## Adding a new slash command

Each command is a self-contained skill under `skills/<name>/SKILL.md`. The
fastest path is to copy an existing one that matches the modality:

- **image** (gpt-image-2) → copy `skills/headshot/` or `skills/poster/`
- **video** (Seedance) → copy `skills/dance/`
- **local authoring/finishing** (no MCP) → copy `skills/launch-film/`

Then:

1. Update the `SKILL.md` frontmatter (`name`, `description`, `allowed-tools`) and
   body. Keep the shared shape: **Inputs** table → ordered **Workflow** →
   **Failure handling** → **Cost** → **Examples**.
2. Put the reusable prompt template in `prompts/<name>.md` and reference it from
   the skill (don't duplicate large blocks — one source of truth).
3. Register the skill in **all three** places or it won't install everywhere:
   `plugin.json` (`skills[]`), `install.sh` (`SKILLS=(...)`), `uninstall.sh`
   (`SKILLS=(...)`). Add it to `INSTALL.md` and the README command list too.
4. Bump `plugin.json` `version` and add a `CHANGELOG.md` entry.
5. Keep costs honest — add a row to `docs/COSTS.md`.

## Adding prompt cases

The case library under `prompts/case-library/` is generated by
`scripts/normalize_case.py` from the upstream awesome-* repos — don't hand-edit
generated files. To refresh: add the source to `REPOS` in `normalize_case.py`,
re-run it, and commit the regenerated library + `INDEX.md`. Attribution and
licensing stay with the upstream sources (see `docs/` / `SOURCES`).

## Style

- No private context, names, or in-jokes in shipped files (CI guards "Your Majesty").
- Deterministic tools only — no `Date.now()`/`Math.random()` in compositions.
- Shell scripts: `set -euo pipefail`, TTY-guard colors, keep them POSIX-bash-3.2 safe.
