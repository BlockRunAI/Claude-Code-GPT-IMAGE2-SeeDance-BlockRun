## Original prompt

Referencia la creatividad publicitaria del video de referencia. Usa la imagen de chaqueta de plumón proporcionada, y referencia la imagen de plumón de ganso y la imagen de cisne. Empareja con el siguiente texto publicitario: "Este es un plumón de ganso, este es un cisne cálido, esta es una chaqueta de plumón de cisne polar usable, úsala cálida para el nuevo año, vive la vida cálida." Genera un nuevo video publicitario de chaqueta de plumón.
